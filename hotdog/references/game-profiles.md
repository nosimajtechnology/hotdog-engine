# Explicit adjacent game profiles

Use only when requested. Preserve identity from the PS2 sheet, translate rendering
through original game evidence using [rendering-grounding.md](rendering-grounding.md).
No alternate canonical sheets are bundled.

| Profile | Resolve from inspected original game | Avoid |
| --- | --- | --- |
| PS1 | Lower mesh density, small textures, filtering, color/shading and camera. Affine wobble, vertex jitter or dithering only when supported by the chosen game. | Every artifact at maximum strength; losing facial identity |
| Early sixth generation / Dreamcast | Game-specific geometry, cleaner texture mapping/filtering, diffuse surfaces, vertex/baked lighting and modest worlds. | Merely blurring PS2 or upgrading to modern CGI |

Pick one lineage appropriate to the scene. A later port/remaster cannot establish
original rendering. Preserve bun count, red core, front-only mustard, compact
paws and rear geometry under reduction. Label new sheets as project studies
until approved. Explicit aspect/camera choices override the 4:3 default.
