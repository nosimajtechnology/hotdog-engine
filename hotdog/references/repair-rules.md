# Inspect and repair

Inspect immediately even if tools display images before inspection. Compare
actual assigned references and latest approved state.

| Priority | Check |
| --- | --- |
| Identity | Face, scale, head placement, silhouette, color |
| Anatomy | Two arms/two legs, short paws/limbs, correct attachments/occlusion |
| Construction | Two bun halves/depth, sausage, front-only mustard, correct rear/nub |
| Continuity | Wardrobe, object owner/condition, geography, completed actions |
| Rendering | No modern materials/density/fur/light or wrong platform |
| Direction | Readable action/contact, motivated coverage, visible payoff |
| Artifact | Correct views/shots; no unwanted collage, duplicates, text/background |

Major identity/anatomy/construction error, wrong-generation rendering or multiple
smaller fidelity failures prevents advancement. Apply one automatic narrow repair
for an isolated defect. If still failing, name the issue and offer focused retry,
simpler staging or alternate route. No unlimited retries or unapproved new canon.

```text
LOCK:
[correct identity, rendering, staging and current project state]

CHANGE ONLY:
[specific failed feature, action, camera or panel]

DO NOT CHANGE:
[protected layers and all successful shots]
```

If only shot 3 has an extra arm, repair that panel and preserve the others. State
correct attachment/occlusion instead of also rewriting camera/lighting. Use the
available image editing mechanism. Reconstruct only the failed frame if identity
and build are fundamentally wrong. When editing unavailable, return the narrow
repair prompt and state it was not visually executed. Log actual outcome;
prompt inspection does not prove visual performance.
