# Provider packaging

Start with [animation-rules.md](animation-rules.md). Verify selected host's live
endpoint, input roles, duration/aspect, resolution, reference budget, prompt limit,
audio and expansion. Record date/official sources. Prefer connected schemas,
otherwise official docs. One host's support does not establish another's.

| Provider | Packaging |
| --- | --- |
| fal H3 Max | Read [fal-h3-max.md](model-adapters/fal-h3-max.md); separate I2V/T2V/R2V roles |
| Seedance | Use selected host's approved frame/storyboard/reference flow. Honor storyboard-only requests. Additional identity references only if needed and supported. |
| Kling | Element/character binding and multi-shot only when host-verified; otherwise approved-frame I2V and ordered shot plan. |
| Generic | Strongest supported authority and prose plan; individual shot prompts sharing a lock if storyboard order is uncertain. Label unknown controls unverified. |

Do not silently change requested route. Explain incompatible route/duration and
offer supported input/edit plan before generation. If schema unavailable during
prompt-only work, deliver useful generic prose without invented settings.

Deliver short setup, actual reference roles if any, final code-block prompt and
verified settings. T2V omits reference/upload language entirely. Each independent
concept receives a complete independent prompt. For exact prompt limits measure
the final block after edits, including reference/timing/negative/audio text, and
report count. Compress atmosphere first, preserving identity, continuity, shot
progression, rendering, motion, decisive exclusions and requested payoff/audio.

Supported prompt packaging does not demonstrate Hotdog video performance. Do
not call any route Hotdog-validated until an actual result for that route has
been reviewed. A prompt request does not trigger video spending or publishing.
