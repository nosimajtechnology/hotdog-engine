| flagship-ps2-v1 | FLAGSHIP PS2 | Bundled approved Hotdog sheet | Original PS2 evidence and rendering contract |

Select automatically; no single-option menu. The sheet's 3:2 page does not set
scene aspect; default scenes to 4:3. This is the only launch style. Do not inherit
aliases, presets, sheets or transformations from other engines.

For explicit PS1 or early-sixth-generation/Dreamcast, load
[game-profiles.md](game-profiles.md) and research the requested original game.
These are project-specific translations, not approved alternate sheets. Use the
actual platform in titles. Preserve base identity and log the translation.

Anime, Late-Z, battle-cel and OVA are not included or registered. If asked for a
bundled excluded style, say it is absent and offer PS2. An explicit request to
develop a new style is separate creative work; do not claim tested support,
silently switch or install an adapter. The same distinction applies to photos,
modern CGI and other unregistered extensions. Only if approved styles are added
later, present them after mode selection; do not create empty adapters now.
