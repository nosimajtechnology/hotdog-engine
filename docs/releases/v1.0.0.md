# Hotdog v1.0.0

Initial self-contained implementation of Hotdog PRD v1.0.

- Exact approved PS2 reference sheet and protected character construction.
- IMAGE, CHARACTER, MINI, SCENE, BUMPER, FAKE AD and progressive EPISODE workflows.
- Automatic original-PS2 grounding and explicit adjacent game translations.
- Classic Control, Direct Explore and Character Lock video routes.
- H3 Max I2V/T2V/R2V packaging, host-verified Seedance/Kling/generic guidance.
- Continuity ledger, reference roles, no-music default and focused repair.
- Deterministic installable ZIP, checksum, validation and release automation.

Install `hotdog.zip`; verify it with `hotdog.zip.sha256` if desired.
See `docs/ACCEPTANCE.md` in the tagged source for actual checks and limitations.
Prompt support does not by itself establish Hotdog video performance.
